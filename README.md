# Apex Dashboard

Build a modern SaaS dashboard using Next.js 15, React, TypeScript and Tailwind CSS.

Requirements:
- Responsive layout
- Sidebar navigation
- Top navbar
- Dashboard home with analytics cards
- Charts section
- Users page
- Settings page
- Dark mode
- Beautiful UI inspired by Linear and Vercel
- Clean folder structure
- Reusable components
- Ready for authentication integration
